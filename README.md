# Gold Portfolio Tracker — Setup for Abrar

## How to deploy your own copy

1. **Fork or download** this folder
2. **Create a free account** at [netlify.com](https://netlify.com)
3. **Deploy** — drag and drop this folder onto Netlify, or connect via GitHub
4. **Open the app** in your browser
5. **Add your lots** using the + button
6. **Get AI Advice** — click the button and enter your own [Anthropic API key](https://console.anthropic.com) when prompted (stored only in your browser, never shared)

## Notes
- Your investment data is stored privately in your own Netlify account
- Your API key never leaves your browser
- Delete the placeholder lots and add your own
